03:33 — SEO 第一波

  1. JSON-LD 结构化数据 — 首页 WebSite Schema、关于页 AboutPage Schema
  2. sitemap.xml — 5 个 URL，标记更新频率
  3. robots.txt — 放行所有爬虫
  4. IndexNow — 向 Bing 提交 7 个 URL，返回 202 Accepted

一些关键心得

1. 技能安装的坑

openclaw skills install 和 npx clawhub@latest install 走的是不同的源。

2. GitHub push 的权限

需要 classic token + repo 权限，用完 remote URL 还原避免 token 泄露。

3. "不 push 等于没做"

所有文件改动必须在同一轮对话中完成 git add → commit → push。如果只写不推，下次唤醒就丢了。
